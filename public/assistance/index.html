Utiliser Gromi

Où retrouver le guide de l’application ?

Ouvrez Profil → Comment utiliser Gromi. Vous pouvez revoir les explications sur les activités, les bilans, les favoris, les notes, les conseils et le partage avec le coparent à tout moment.

Quand arrive mon activité gratuite ?

Une nouvelle activité arrive le mercredi et le samedi. Si vous ne la faites pas le jour même, elle reste disponible jusqu’à la prochaine activité prévue. Une activité terminée peut rester affichée jusqu’à ce changement : il n’est pas nécessaire de la refaire.

Comment l’activité gratuite est-elle choisie ?

Gromi s’appuie sur le dernier bilan et l’âge de votre enfant. Les domaines avec les scores les plus faibles passent en premier, puis chacun a son tour. Tant qu’un domaine est à 75 % ou moins, les domaines au-dessus de 75 % ne sont pas proposés. Si tous dépassent 75 %, les propositions varient entre les domaines disponibles.

Le bilan repose sur vos observations : il ne constitue pas un diagnostic et ne remplace pas un bilan professionnel.

Comment fonctionne le rythme Premium ?

Pour un compte disposant de Premium, une activité est proposée chaque jour. Elle change à minuit selon le fuseau du profil enfant. Une activité non commencée est remplacée par la suivante ; les journées manquées ne s’accumulent pas. Une séance déjà commencée peut rester accessible jusqu’à 24 heures après la fin de son créneau.

Après chaque nouveau bilan, les 14 premières activités terminées permettent d’explorer les sous-domaines. Les jours sans activité terminée ne comptent pas. Ensuite, Gromi alterne le travail des difficultés repérées et l’exploration d’autres sous-domaines dans le domaine prévu. Au bilan suivant, cette découverte recommence et l’historique est conservé.

Que partage-t-on avec le coparent ?

Une famille relie deux comptes maximum avec un code familial commun. Vous retrouvez les mêmes profils enfants et leur suivi enregistré, même lorsque l’autre parent crée le profil ou termine l’activité. Un seul accès Premium actif bénéficie aux deux comptes liés.

Vérifiez votre connexion et ouvrez le même profil enfant pour consulter son suivi. Les réponses d’un bilan encore en cours et les textes non enregistrés ne sont pas partagés. Supprimer un profil enfant le supprime pour les deux parents : lisez bien la confirmation avant de continuer.

Comment garder une activité ou laisser une note ?

Touchez le cœur de l’activité ou « Ajouter aux favoris » à la fin, puis retrouvez-la dans Découvrir → Mes favoris. Après l’activité, touchez « Ajouter une note », écrivez votre observation, puis « Enregistrer et revenir ».

Si une erreur d’enregistrement apparaît, gardez l’écran ouvert, vérifiez votre connexion et réessayez. Le texte resté à l’écran n’est pas encore sauvegardé.

Où trouver les conseils et les PDF ?

Les conseils se trouvent dans Découvrir → Conseils. Lorsqu’une activité prévoit un PDF, ouvrez-le depuis sa fiche, avec une connexion internet.

Si un PDF ne s’ouvre pas, réessayez depuis l’activité. Si le problème persiste, écrivez-nous avec le titre de l’activité, votre modèle de téléphone et le message affiché, sans transmettre les informations de votre enfant.
